## 第5章核心内容（The CMOS Inverter）
1. 静态特性（5.2, 5.3）
- CMOS 反相器由 PMOS 上拉和 NMOS 下拉构成，输入低输出高，输入高输出低。
- 关键静态指标：切换阈值 `VM`、噪声容限 `NMH/NML`、VTC 曲线斜率（增益）。
- 通过调节 `Wp/Wn`（等效驱动比）可移动 `VM`，在抗噪与门级接口之间权衡。

2. 动态特性（5.4）
- 延时由负载电容 `CL` 与等效导通电阻决定，一级近似满足 RC 延时模型。
- 主要延时指标：`tpHL`、`tpLH`、`tp = (tpHL + tpLH)/2`。
- 输入斜率、扇出、级联缓冲级数与尺寸因子都会显著影响传播延时。

3. 功耗与能量（5.5）
- 动态功耗主项：`Pdyn = alpha * CL * VDD^2 * f`。
- 短路功耗在输入翻转期间出现，受输入上升/下降时间和负载影响。
- 静态功耗来源于漏电（亚阈值、结漏电等），低阈值器件会提升速度但增大泄漏。
- 能量-延时存在最优供电电压与最优尺寸点，需要在性能和能效之间折中。

4. 技术缩放视角（5.6）
- 工艺缩放一般降低门延时，但功率密度与互连影响会逐步成为限制因素。
- 随着代际演进，互连延时在总延时中的占比上升，版图/布线优化变得更关键。
